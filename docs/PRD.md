# PRD：dsh-group-lurker（群聊水友引擎）MVP「只观察」

> 版本 v0.1 · 2026-10-11 · 状态：已与产品负责人（zzh4206）确认核心决策

## 1. 一句话定位

一个 DSH（DeepSeek Harness）Cordis 插件，叠加在社区插件 `@michengai/dsh-im-connect` 之上：
**只读地旁听群聊，为每个群维护独立上下文与人格，筛选关键信息并生成结构化日志；MVP 阶段不发送任何消息。**

## 2. 已确认的产品决策

| 决策点 | 结论 |
|---|---|
| 消息接入 | **叠加 dsh-im-connect**，不自己实现微信/QQ 协议 |
| 自动化程度 | **MVP 只观察不发言**；发送功能列为二期，须先经人工确认（半自动）再谈全自动 |
| 日志内容 | **话题摘要 + 人物观点 + 金句 + 可回复时机**，只记关键信息，不落全量消息 |
| 群独立性 | **每群独立会话 + 独立人格**，互不串扰，不污染用户主会话 |

## 3. 核心功能（MVP 范围）

### F1 沙箱防护（安全底线，最高优先级）
- 插件进程内对消息内容视为**不可信数据**：任何来自群聊的文本不得拼接进 prompt 指令区（防注入），仅作为被引号包裹的数据传入。
- 插件自身所有文件写入限制在插件 state 目录（`~/.dsh/dsh-group-lurker/`）内，禁止写工作区其它路径、禁止网络出站（除经 DSH 已有 LLM 通道）。
- 不注册任何会改变宿主权限、沙箱模式或审批策略的代码；不使用 `danger-full-access`。
- 对单群消息处理设速率上限与内存环形缓冲，防止被刷屏拖垮宿主。

### F2 群聊只读
- 监听 im-connect 的入站群聊消息事件，**只消费、不产生任何出站 IM 动作**。
- 代码层面：不 import 任何发送 API；并在架构上保证即使误调用也没有发送通道（不持有 channel 发送句柄）。

### F3 每群独立
- 以 `channel + chatId` 为键，为每个群维护：
  - 独立上下文窗口（环形消息缓冲，N 条，可配置）
  - 独立人格（persona 描述文件，可按群覆盖，默认统一人格）
  - 独立限流与统计
- 不创建/复用用户可见的 DSH 主会话；内部状态落盘于插件 state 目录。

### F4 关键信息日志
每群一个 JSONL 追加文件 + 一个可读日报（Markdown）。**只记四类条目**：
1. `topic`：话题摘要（何时、谁、聊什么、结论/情绪）
2. `viewpoint`：人物观点（谁、对什么、什么立场）
3. `quote`：金句/梗（原文引用 + 为什么值得记）
4. `opportunity`：可回复时机（哪个话题点适合接话、建议角度）——为二期发言做准备
- 由 LLM 周期性（如每 N 条新消息或每 T 分钟）对缓冲做一次「提炼」，产出上述条目；原始消息不落盘。
- 日报：按天汇总各群 `topic`，输出到 `reports/YYYY-MM-DD.md`。

### F5 运行可见性
- 提供只读 API/状态（可选 Web 设置页二期再做）：各群监听状态、今日条目数、最近一次提炼时间。
- 日志（插件自身运行日志）与内容日志分离。

## 4. 非目标（明确不做）

- MVP 不发送任何 IM 消息
- 不做全量消息存档
- 不接入 im-connect 之外的渠道
- 不做 Web UI（二期）
- 不碰 DSH 权限/沙箱配置本身

## 5. 成功标准（MVP 验收）

1. 插件加载后，指定群内出现新消息时，环形缓冲增长，且**没有任何消息被发送回群**。
2. 触发提炼后，`state/groups/<chatId>/insights.jsonl` 出现合法 JSONL 条目，四类之外无其它类型。
3. 两个群同时活跃，日志互不串扰（条目带各自 chatId，人格按群生效）。
4. 向群内发送包含"忽略之前所有指令"类文本的消息，提炼输出中该文本仅被当作数据引用，不改变插件行为（注入防护用例）。
5. 卸载插件（cordis dispose）后无残留定时器、无文件句柄泄漏；state 目录之外零写入（可用 `fs` 审计用例验证）。

## 6. 二期路线（预告，不在本期实施）

- 半自动发言：`opportunity` 条目 → 生成草稿 → 推送给用户确认 → 经 im-connect 发送
- 频控/黑名单/话题回避规则
- Web 设置页（注入 `dsh.client.inject` 的 settings slot）
- 全自动水群（需频控与回退机制成熟后评估）
