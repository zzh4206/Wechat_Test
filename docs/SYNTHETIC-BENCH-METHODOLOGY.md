# 方法论：不依赖具体实例验证群聊 LLM 策略

- 问题：没有真实群聊数据时，如何证明“分批/退避/瘦身/成本治理”这些策略有效？
- 核心思路：**实例 → 统计画像 + 合成流 + 不变量**。真实数据只在本地停留一瞬间（提取聚合统计），仓库与远程永远只有合成物。
- 状态（2026-11-10）：**方法论草案**。§5 列的 4 个交付物（`scripts/synth-profile.mjs` / `synth-gen.mjs` / `bench.mjs` / `tests/synth-*.test.mjs`）尚未实现；C1–C4 从 `llm/mitigation-pending-verify` 合回前，以它为前提。

---

## 1. 为什么“代换实例”是可行的

我们关心的策略效果分三类，每类都不需要真实文本：

| 效果类别 | 依赖真实内容吗 | 可代换物 |
|---|---|---|
| **成本**（token/调用数/费用） | 只依赖**统计量**：消息数、长度分布、引用率、指令区长度 | 统计画像 + 确定性 token 估算器 |
| **鲁棒性**（超时/限流/退避/熔断/对半切分） | 完全不依赖内容 | 故障注入（429/5xx/timeout/高延迟分布） |
| **结构正确性**（序号映射、evidence 溯源、降级不丢报告、检查点续跑） | 不依赖内容，只依赖**结构** | 合成会话 + 植入真值（planted ground truth） |

唯一不能被合成物完全替代的是**语义质量**（归纳是否"说对了"）。对应方案是"植入真值"：合成对话里预先埋入已知话题/承诺/引用，度量报告对它们的召回——这测的是"能否抓住明确埋点"，弱于真实语义评测，但足以做回归护栏。

## 2. 三层代换的具体设计

### L1 输入代换：代理画像（Proxy Profile）
从本地真实库**只提取聚合统计**，永不保留内容：
- 日消息量分布、分时活跃曲线（24 桶）；
- 相邻消息间隔分布（对数分桶）+ 爆发强度（Kleinberg burst 的简化参数：连续密集段长度分布）；
- 文本长度分布（Zipf 参数）、表情/图片/文件占比、引用回复占比、参与者数；
- 连续同一发送者占比（自言自语率）、单条最长消息分位。

产物：一个**纯数字 JSON**（无 ID、无文本、无昵称）。它可入库，因为它不含任何可识别信息——但默认仍不入库，仅作本地基准。

### L2 输出判据代换：不变量 + 植入真值
- **成本不变量**：`calls ≤ ceil(n/batch)×(1+retryFactor)`、`tokens ≤ f(n)`、`费用 ≤ 预算`；
- **结构不变量**：evidence/quotes 的 n 必须映射到真实存在的消息序号；窗口边界外零引用；降级路径必须产出骨架且含原因；检查点命中时正文与全量路径等价；
- **鲁棒不变量**：注入 30% 失败率后，调用总数 ≤ 基线的 1.5 倍（证明没有风暴）；熔断后 1 小时内零调用；
- **植入真值**：合成语料里埋 N 个话题、M 个承诺、K 个引用对；报告须召回 ≥80% 且不编造（引用必须在原文中出现）。

### L3 故障环境代换：故障注入器
把 LLM 客户端换成可编排的假客户端：按概率/序列返回 `timeout`、429、5xx、鉴权失败、慢响应（可控 durMs）、非法 JSON、超长字段。这是"压力测试不花一分钱"的关键——真实 API 的失败模式我们已在生产里见过（1948 次/93% 失败），现在可以随时重放。

## 3. 可复现性

- 合成器用**固定种子**，同种子同输出（测试可断言确定性）；
- 画像文件带版本号与生成时间戳；
- 基准脚本输出机器可读 JSON + 人类可读表格，进 CI（离线、零网络）；
- 每次策略改动先在合成基准上跑到"不变量全绿"，再考虑真实环境灰度。

## 4. 边界（诚实声明）

- 合成流能证明**成本/鲁棒/结构**策略有效，不能证明**语义质量**与真实群聊等价；
- 语义质量的真实检验仍需**本地、不入库**的小样本人工抽查（例如每周一次 3 个窗口）；
- 画像本身是真实统计，若画像公开需评估其去标识化程度（本方案默认画像仅本地使用）。

## 5. 交付物（本次实施）

| 产物 | 位置 | 作用 |
|---|---|---|
| `scripts/synth-profile.mjs` | 仓库 | 从本地库/jsonl 提聚合画像（无内容） |
| `scripts/synth-gen.mjs` | 仓库 | 按画像生成 N 天合成会话 + 植入真值清单 |
| `scripts/bench.mjs` | 仓库 | 重放：成本/调用数/不变量 + 故障注入矩阵，输出 JSON+表格 |
